- 背景：用户用 TortoiseGit（小乌龟）在该目录右键「拉取」失败。根因是该目录当时是**空文件夹**（无 `.git`），不是 Git 仓库；「拉取」需要已有 origin，首次接入应使用「克隆」。
- 处理：
  - 用 `git clone https://github.com/wjzhaoo/llm-game-arena.git .` 克隆到 `D:\wjz\projects\app\llm-game-arena`，默认分支 `main`，跟踪 `origin/main`。
  - 全局配置 `credential.helper = manager`（本机 Git 自带 GCM 2.9.0）。本机 Git 安装在 `D:\softs\install\Git`（非默认 Program Files），TortoiseGit 安装在 `D:\softs\install\TortoiseGit`。
  - 全局 `user.name` 由 `DESKTOP-GMOA76J\Administrator` 改为 `wjzhaoo`，`user.email` 保持 `wjzdreamingg@gmail.com`。
- 项目要点：零 npm 依赖，Node ≥ 22.13；`npm start` = `node server.mjs`，监听 `127.0.0.1:4318`；端口用 `PORT`，数据目录用 `ARENA_DATA`（默认 `.arena/`）。管理码仅存进程内，重启更换；可用 `ARENA_ADMIN_TOKEN` 固定。
- 验证：`node --test test/*.test.mjs` 76/76 通过；服务启动后 `GET /` 返回 200。
