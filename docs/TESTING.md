# 验证与手动验收

自动：`npm test`。所有测试使用本机临时目录、模拟 provider 与隔离 token，不连接真实模型、不消耗模型 API。覆盖开局合法着、兵/将/士/象/马/车/炮、将军/照面/将死/困毙、三次重复/上限，六人角色构成、秘密投影、夜间选择/平票/药剂/同步死亡/胜负/20轮终止，HTTP 认证与跨源、attempt 所有权、重复与冲突回执、错误预算、时限、重启恢复及撤销。

手动流程：
1. `npm start`，普通页可看房间但无权创建；管理码错误时显示错误
2. 取消管理/创建/邀请弹窗，重复打开；输入仅当前标签页保存，不进入 URL
3. 创建象棋房；为红、黑、裁判生成各自邀请。第二次使用同一邀请必须拒绝
4. 用两个独立工具会话和一个裁判会话 connect；未全员就绪时不能开始
5. 红方 claim/submit 开局兵一步；观察网页两秒内刷新、黑方才收到行动
6. 原返回重复提交幂等；更换 result 冲突；用黑方 token 提交红方 attempt 拒绝
7. 提交非法棋步两次或等待超时；观察固定胜负与裁判结构化结论
8. 创建狼人杀，6位选手+裁判；普通网页与裁判不能看到隐藏角色和夜间目标
9. 管理全知视图有醒目警示；未认证直接访问 reveal 必须拒绝；关闭恢复公开投影
10. 完成夜间/讨论/投票；时间轴拖动回放，回到实时；回放不带后来的角色翻牌
11. 撤销一位连接后旧 token 和 attempt 拒绝，新邀请可接续，不重置期限
12. 正常停服重启同一数据目录，历史与进度仍在；进程崩溃遗留锁须人工确认进程停止后再处理，不自动删除锁

限制：当前运行实测 Node 24.19.0；Windows 启动助手未在 Windows 实机验证。外部真实平台接入、长时间压力、移动端实机及完整无障碍审计未执行。公开网页轮询刷新为2秒；大量历史尚无分页，定位本地少量并行房间。未实现厂商原生宿主认证、推送唤醒、公网 TLS 或账号系统。
